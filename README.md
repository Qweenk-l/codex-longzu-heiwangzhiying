# 龙族：黑王之影 · 序章至第五章试玩

独立 Vue 3 + TypeScript + Vite 程序。当前接入范围为序章至第五章；第五章末明确停在试玩终点，尚不代表第一季通关。

最新阶段、待确认事项及每次增删改统一查看[项目总进度表](../04-开发规划/项目总进度表.md)。每次工作开始先读总表，交付前同步实际变化；本 README 主要保留启动与程序结构说明。

章节测试通过“打开章节列表”进入右侧抽屉。序章至第五章均可独立测试；后续实际进入运行包的章节自动显示为可测试项。列表独立滚动，可通过关闭按钮、Esc或遮罩关闭。

阅读按“当前合并页 + 选项”呈现：选择后，上一选择的结果、自动承接和下一场正文一起成为新页，从页首阅读，不加“继续”按钮。顶部“剧情记录”可只读回看完整旧页，与检查点回退分开；主阅读/行动区保持70% / 30%。本次规则直接更新在主程序设计方案v0.2中。

## 启动

依赖已安装时，可双击本目录的 `启动试玩.cmd`，终端与浏览器会打开；关闭终端即停止本地服务。若已经在运行，直接访问下列地址即可，不必再启动一份。

需要 Node.js 24.0 及以上的 24.x 版本（本次使用 24.19.0）。在此目录执行：

```powershell
npm.cmd install
npm.cmd run dev -- --port 5173 --strictPort
```

然后打开 http://127.0.0.1:5173 。使用同一浏览器、同一地址续读，换浏览器或地址请先导出存档。

## 结构与资料

- `src/content/stage-one.json` 是程序运行副本；`content-source` 保留本次生成依据，`scripts/build-content.mjs` 可复现生成。
- `src/engine` 独立处理条件、选择、自动段落、检查点及章节前情。
- `src/storage` 使用 IndexedDB；导入会重放合法选择校验全部剧情状态。
- `src/components` 和 `src/style.css` 负责阅读呈现；70/30 双区为首版固定约定。正文、安全加粗渲染与玩法状态分离，后续美术及视听功能可以在表现层增加。
- AI、其他角色、第六章及之后、音乐和正式美术尚未实装。当前输入只匹配可见的脚本选项。

内容真值仍为上一级项目的当前参考稿；序章至第二章以 v0.4B 为准，第三至第五章以 v0.5D 为准；三处早期修正和本轮第五章两处获批修正仅应用运行副本。详情见 `docs/content-mapping.md`、`docs/第三至第五章内容接入映射.md` 和上一级的接入审计。

自动存档受当前浏览器存储条件影响。清除网站数据会删除本地进度；导出文件可在另一浏览器通过导入恢复。当前运行包 `v0.5D-stage-two.2` 支持本程序 `v0.4B-stage-one.1` 至 `.5` 的已知存档升级：先严格校验旧会话，再重放到新版本；原第二章终点存档会接续第三章；不兼容旧游戏存档或任意剧情版本。
