# 序章至第二章实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 交付可在本机浏览器游玩的序章、第一章、第二章，供用户正式验收剧情及基础体验。

**Architecture:** 独立 Vue 3 + TypeScript + Vite 工程，纯函数剧情引擎处理 JSON 内容，界面只呈现引擎结果。存档独立于界面；章节测试通过原著贴近路线重放产生，不影响正式游玩。

**Tech Stack:** Vue 3、TypeScript、Vite、Vitest、IndexedDB、Playwright。

**Spec:** 2026-09-04-主程序设计方案-v0.2.md，及用户后续确认。

## 全局约束

- 程序目录为 `05-游戏程序`；旧项目和参考稿均保留不改。首阶段只到第二章，不宣称第一季完成。
- JSON 保留节点和旗标的可追溯性；序章至第二章差异以 v0.4B 为准。v0.5D、v0.7C 用于后续章节。
- 用户 2026-09-04 已同意三处运行正文最小修正：CH2-12 告白字母改喧闹；DIGNITY 共同正文取消玩家此时才知情；CANON 已问出真相路线使用已知情版本。具体原文/替换见接入审计。
- 不接入 AI、不加中途继续按钮、不自动改写剧情。自动段落连续追加，选择反馈必须保留。
- 主阅读区域固定上 70% 正文、下 30% 行动，两区独立滚动。行动数量不改变分区；界面可后续替换。
- 新内容定位于新增部分开头；回看历史时不抢滚动。字号 16/18/20，默认 18；明暗主题。
- 正式存档与章节测试隔离；回退删除未来选择、正文和检查点；导入失败保留现有存档。
